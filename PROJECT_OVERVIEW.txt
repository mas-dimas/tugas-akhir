1. TUJUAN PROYEK
================================================================================
Sistem web berbasis Laravel 11 untuk mengelola pendaftaran perlombaan dengan 
dua peran pengguna (Admin dan Peserta) yang dapat saling berinteraksi dalam 
proses pendaftaran, submission dokumen, dan review.


2. TEKNOLOGI YANG DIGUNAKAN
================================================================================
Backend              : Laravel 11 (PHP 8.2+)
Frontend             : Blade Templates, Tailwind CSS, Alpine.js
Database             : MySQL
Authentication       : Laravel Breeze
Build Tool           : Vite, npm
Testing              : PHPUnit


3. ARSITEKTUR SISTEM
================================================================================

Model Data (Database):
-----------
5 Model Utama:
├── User (dengan role: admin/peserta)
├── Competition (Perlombaan)
├── Registration (Pendaftaran Peserta)
├── DocumentTemplate (Template Dokumen untuk setiap lomba)
└── SubmissionDocument (Dokumen yang di-upload peserta)


Relasi Database:
-----------
1 Kompetisi ──────────── N Pendaftaran ──────────── N Dokumen Upload
                                ↓
                           1 User/Peserta
                           
1 Kompetisi ──────────── N Template Dokumen


4. FITUR UNTUK ADMIN
================================================================================
1. CRUD Perlombaan
   - Tambah perlombaan baru
   - Lihat daftar perlombaan
   - Edit data perlombaan
   - Hapus perlombaan

2. Upload Media
   - Upload poster untuk setiap lomba
   - Upload guidebook/panduan perlombaan

3. Kelola Template
   - Buat template dokumen yang diperlukan
   - Template: Proposal, Surat Rekomendasi, dll

4. Review Peserta
   - Melihat daftar peserta yang mendaftar untuk setiap lomba
   - Melihat detail pendaftaran setiap peserta

5. Koreksi Dokumen
   - Review dokumen yang di-upload peserta
   - Memberikan status pada dokumen (Belum Dikoreksi / Terdapat Koreksi / Tidak Ada Koreksi)

6. Feedback
   - Memberikan catatan/feedback ke peserta melalui field notes


5. FITUR UNTUK PESERTA
================================================================================
1. Browse Perlombaan
   - Melihat daftar semua perlombaan yang tersedia
   - Melihat informasi lengkap perlombaan

2. Detail Perlombaan
   - Melihat deskripsi, tahapan, dan informasi perlombaan
   - Download guidebook dan poster

3. Pendaftaran
   - Mendaftar untuk mengikuti perlombaan
   - Menyimpan informasi registrasi

4. Upload Dokumen
   - Upload proposal sesuai template
   - Upload surat rekomendasi sesuai template
   - Bisa upload ulang jika ada koreksi

5. Track Status
   - Melihat status review dokumen dari admin
   - Mengetahui dokumen mana yang sudah dikoreksi

6. Lihat Feedback
   - Menerima catatan/masukan dari admin
   - Memahami perbaikan yang diperlukan

9. KEAMANAN & KONTROL AKSES
================================================================================

Authentication:
- Menggunakan Laravel Breeze
- Login dengan email dan password
- Password di-hash dengan bcrypt

Authorization (Kontrol Akses):
- Middleware `role:admin` untuk route admin
- Middleware `role:peserta` untuk route peserta
- Smart redirect di /dashboard berdasarkan role

Route Protection:
- /admin/* → Hanya admin yang bisa akses
- /peserta/* → Hanya peserta yang bisa akses
- /dashboard → Redirect ke dashboard sesuai role


10. STATUS DOKUMEN (Document Workflow)
================================================================================

Setiap dokumen yang di-upload memiliki lifecycle:

┌─────────────────────────────────────────────────────────┐
│ BELUM DIKOREKSI                                         │
│ Dokumen baru saja di-upload oleh peserta               │
│ Status awal sebelum admin review                        │
└─────────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────────┐
│ TERDAPAT KOREKSI (or) TIDAK ADA KOREKSI                │
│ Admin sudah mereview dan memberi status                 │
│ Field 'notes' berisi feedback dari admin               │
└─────────────────────────────────────────────────────────┘
                        ↓
Jika ada koreksi:
┌─────────────────────────────────────────────────────────┐
│ PESERTA UPLOAD ULANG                                    │
│ Peserta melihat feedback dan upload versi baru          │
│ Kembali ke status BELUM DIKOREKSI                       │
└─────────────────────────────────────────────────────────┘


11. DATABASE SCHEMA OVERVIEW
================================================================================

USERS Table:
- id (primary key)
- name
- email
- password (hashed)
- role (admin / peserta)
- timestamps

COMPETITIONS Table:
- id (primary key)
- title
- description
- stages
- poster_path
- guidebook_path
- source_link
- timestamps

DOCUMENT_TEMPLATES Table:
- id (primary key)
- competition_id (foreign key)
- type (proposal / surat_rekomendasi)
- template_file_path
- timestamps

REGISTRATIONS Table:
- id (primary key)
- user_id (foreign key)
- competition_id (foreign key)
- status
- timestamps

SUBMISSION_DOCUMENTS Table:
- id (primary key)
- registration_id (foreign key)
- type (proposal / surat_rekomendasi)
- file_path
- status (belum_dikoreksi / terdapat_koreksi / tidak_ada_koreksi)
- notes
- timestamps

13. INSTALASI & SETUP
================================================================================

1. Clone Repository
   git clone <repository-url>
   cd tugas-akhir

2. Install Dependencies
   composer install
   npm install

3. Setup Environment
   cp .env.example .env
   php artisan key:generate

4. Konfigurasi Database
   Edit .env file:
   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=nama_database
   DB_USERNAME=username
   DB_PASSWORD=password

5. Migrasi & Seeder
   php artisan migrate
   php artisan db:seed

6. Setup Storage Link
   php artisan storage:link

7. Build Assets
   npm run dev        (untuk development)
   npm run build      (untuk production)

8. Jalankan Server
   php artisan serve

9. Akses Aplikasi
   http://localhost:8000
